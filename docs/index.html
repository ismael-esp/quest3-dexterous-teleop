VR teleoperation · hand retargeting · demonstration collection

Quest 3 Hands → Two Arms, Two Allegro Hands

The operator wears a Meta Quest 3 and sees the simulated dual-arm cell in stereo from the robot's head. Both UR3 arms follow the operator's wrists and both 16-DoF Allegro hands follow their fingers, while every step is recorded as a demonstration for imitation learning.

Code & setup guide Assets & recorded demos Glove retargeting (GeoRT)

How it works

01
TrackThe Quest 3 streams 26 joints per hand and the head pose through NVIDIA's CloudXR runtime (or a WebXR page as a lighter alternative).
02
Retarget the handsKeypoints in the wrist frame → vector retargeting on wrist→PIP/DIP/tip, an angle-mapped thumb, pinch snapping and a One-Euro filter → 16 Allegro joints per hand.
03
Drive the armsA clutch anchors each wrist to its end-effector; differential IK then follows the hand 1:1 with a lead clamp.
04
RecordEach step stores observations, the 44-D action, robot, object and fingertip state and the raw hand tracking; a converter builds a fixed-length BC dataset.

Run it

git clone https://github.com/ismael-esp/quest3-dexterous-teleop.git && cd quest3-dexterous-teleop
conda activate env_isaaclab                      # Isaac Lab 2.3 / Isaac Sim 5.1
pip install -r requirements-isaac.txt
scripts/download_assets.sh && scripts/setup_cloudxr_env.sh
scripts/cloudxr_service.sh                       # terminal 1, then connect the headset
GPU=0 DEVICE=cpu scripts/run_cloudxr_teleop.sh --object rod     # terminal 2: A start, F finish, S/N/D label

No headset? scripts/run_teleop.sh --fake_vr --auto_engage --steps 600 runs a scripted episode end to end.
